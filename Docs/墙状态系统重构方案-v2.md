# 墙状态系统重构方案 v2

> 基于 v1 方案（Docs/墙状态系统重构方案.md）+ 讨论结论，2026-07-22

---

## 一、状态划分（核心原则）

**地面状态（grounded=true）**
- 不检测墙。贴着墙走、跳都不进墙系统。

**空中状态（!grounded）**
- 两条射线（脚+头）同时命中墙 → 进入下滑。
- 这是墙系统的**唯一入口**。

**主动状态（Dash/Stomp/击退/击飞）**
- 不归墙系统管。各状态自己处理撞墙逻辑。
- 击退把 player 扔到墙上 → 击退系统自己处理，不进下滑。

## 二、四个墙状态

### 下滑

- 入口：空中 + 两条射线都命中
- **起跳保护**：进下滑时如果 velocity.y > 0（正在上升），不钳制 Y 速度，等它自然降到 ≤0 再开始下滑
- Y 速度钳制：不超过 -slideSpeed
- S 按住 → 加速下滑（slideSpeed × fastMultiplier），不独立成状态
- 水平朝墙方向输入 → X 设 0（阻止嵌入墙体）
- 退出：不贴墙或落地 → null
- W 按住 N 秒 → 爬墙
- Space → 登墙跳

### 爬墙

- 固定上移速度 = climbSpeed
- 水平朝墙方向阻止
- 松 W → 回到下滑
- 头顶无墙 + 翻顶检测通过 → 翻顶
- 退出：不贴墙或落地 → null

### 登墙跳

- 只保留**远离墙方向**，删掉朝上跳和登墙跳两个分支
- 方向：恒定反墙方向弹出
- 设 FreezeTimer 防立刻重新贴墙
- 调用 ClearWallContact
- 执行后退出到 null

### 翻顶

- 触发条件：脚射线命中 + 头射线未命中（= 半身高或已近墙顶）
- 且翻顶点位检查通过：
  - 上方无障碍（不会被天花板卡头）
  - 前方无障碍（不会卡进墙里）
  - 目标位置下方有地面（不会翻过去掉下去）
- 瞬移到墙顶平台上方
- FreezeTimer = 0.15s
- 退出到 null

**翻顶特殊情况**：如果 player 从远处跳到墙一半高度，脚碰墙但头在墙顶之上 → 不进翻顶。此时两条射线不同时命中 → 不进墙系统 → 自然下坠 → 脚踩墙顶 → grounded=true → 站上去。不需要墙系统插手。

## 四、和 PlayerController 的接口

**OnUpdate 调用顺序：**
```
UpdateCooldowns
→ Dash 检查（主动状态，跳过后续）
→ 墙入口检测（空中+双射线→下滑）
→ 墙状态机 Update（驱动当前状态）
→ 墙出口检测（不贴墙/落地→null）
→ 普通跳跃/移动
```

**墙状态活跃时：** FixedUpdate 跳过普通移动（保留现有逻辑）。

**和主状态的关系：**
- 墙状态机独立运行，不属于 PlayerController 的普通移动/跳跃逻辑
- Dash/Stomp/击退等主动状态期间，墙检测暂停（由各主动状态自己管理）

## 五、架构简化

**文件结构（从 8→5 或更少）：**

```
WallConfigSO            ← ScriptableObject，聚合所有墙参数（18个，原分散在两文件）
WallSystem              ← MonoBehaviour，统一管理墙检测+状态机+FreezeTimer
  ├── WallSlideState    ← 下滑（内含加速下滑逻辑，不独立成类）
  ├── WallClimbState    ← 爬墙
  ├── WallJumpState     ← 登墙跳（仅远离墙方向）
  └── WallVaultState    ← 翻顶
```

**消除的问题：**
- FastSlide 不独立成类，仅通过参数控制
- 状态类不再 cast 到 PlayerController 拿子状态引用
- FreezeTimer / ClearWallContact 由 WallSystem 统一管理
- 翻顶逻辑不再三处散落

**注意：** WallConfigSO 聚合参数后，PlayerController 和 PlayerCharacterBase 中原有的墙字段需要清理，Inspector 引用迁移到 SO。

## 七、和 v1 方案的差异

| 项目 | v1 | v2 |
|------|----|----|
| 墙入口 | 空中+贴墙 | 空中+双射线同时命中（更精确） |
| 接地行为 | 接地退出 | 接地不检测墙（从源头阻断） |
| 起飞保护 | 无 | velocity.y>0 时不钳制 Y |
| 登墙跳 | 三方向 | 仅远离墙方向 |
| 击退/主动状态 | 未讨论 | 明确不归墙系统管 |
| Dash撞墙 | 未讨论 | Dash自己管，不进墙 |
| 自然落墙顶 | 未讨论 | 不触发翻顶，自然下坠站上去 |

## 八、翻顶触发条件（待最终确认）

脚射线命中 + 头射线未命中 + 翻顶点位检查通过 → 翻顶。

**仍有疑点的场景：**

1. 从远处跳过来，恰好脚碰到半身高墙边缘 → 当前逻辑会触发翻顶。需要前方检查拦住还是允许？
2. 从矮墙下方起跳，头已过墙顶但脚还在墙范围 → 不进翻顶（头射命中了），自然下坠站上去。确认这是期望行为。
3. 翻顶点位检查当前没有"目标位置下方有地面"的检查（CanVault 只查上方和前方）。需要补。
