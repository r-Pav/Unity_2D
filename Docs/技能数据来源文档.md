## 一、技能数据全景

```
                    ┌─────────────────────────────────┐
                    │        SkillData (基类)           │
                    │  skillName / desc / icon          │
                    │  hotkey / cooldown / manaCost     │
                    │  type / category / skillLevel     │
                    │  unlockLevel / vfx / sfx          │
                    └───────┬─────────┬───────────────┘
                            │         │
         ┌──────────────────┤         ├──────────────────┐
         ▼                  ▼         ▼                  ▼
  ActiveSkillData   PassiveSkillData  WeaponSkillData  BarrierSkillData
  (Q/E主动分支)     (25个被动节点)     (5种武器)        (障碍球)
         │
         ▼
  CombinationSkillData
  (3个组合产出)
```

**5 种 ScriptableObject 子类，共 35 个 .asset 文件。**

## 二、数据在哪儿创建

### 2.1 编辑器工具（Editor Menu）

所有技能 SO 资产通过 Unity Editor 菜单工具**一键批量创建**，不是手动创建。

| 菜单路径 | 创建的资产 | 数量 | 输出目录 |
|---------|-----------|------|---------|
| `Tools → Create ActiveSkillData Assets (Q/E)` | Q 能量球 + E 冲进步 | 2 | `Assets/Resources/Skills/Active/` |
| `Tools → Create All PassiveSkillData Assets` | 5线 × 5层 = 25个被动节点 | 25 | `Assets/Resources/Skills/Passive/` |
| 未自动化（手动创建） | 5 武器 + 3 组合 + SynergyConfig | — | `Assets/Resources/Skills/Weapon/` `Combo/` |

### 2.2 对应脚本

| 编辑器工具 | 脚本位置 |
|-----------|---------|
| 主动技能创建 | `Assets/Scripts/Editor/CreateActiveSkillDataAssets.cs` |
| 被动技能创建 | `Assets/Scripts/Editor/CreatePassiveSkillDataAssets.cs` |

### 2.3 数值来源

编辑器工具脚本中**硬编码了数值表**。以被动技能为例：

```csharp
// CreatePassiveSkillDataAssets.cs 第 174-181 行
static readonly float[] DamageLineValues    = { 0, 0.08f, 0.15f, 0.22f, 0.28f, 0.35f };
static readonly float[] AttackSpeedValues   = { 0, 0,     0,     0.10f, 0.15f, 0.20f };
static readonly float[] MoveSpeedValues     = { 0, 0.06f, 0.12f, 0.18f, 0.24f, 0.30f };
static readonly float[] DodgeValues         = { 0, 0,     0,     0.15f, 0.20f, 0.30f };
static readonly float[] DamageReductionValues = { 0, 0.05f, 0.10f, 0.15f, 0.20f, 0.25f };
// ...
```

**策划改数值的方式：修改编辑器脚本中的常量数组 → 重新运行 Tools 菜单 → 覆盖 .asset 文件。**

## 三、数据结构详解

### 3.1 SkillData（基类）

```csharp
// 位置: Assets/Scripts/Skills/SkillData.cs
[CreateAssetMenu(fileName = "Skill_", menuName = "Game/SkillData")]
public class SkillData : ScriptableObject
{
    // 基础信息
    string skillName;        // 显示名称
    string description;      // 描述文本
    Sprite icon;             // 图标

    // 输入
    KeyCode hotkey;          // 快捷键（Active/Toggle 用）

    // 消耗
    float cooldown;          // 冷却时间（秒）
    float manaCost;          // 法力消耗

    // 分类
    SkillType type;          // Active / Passive / Toggle
    SkillCategory category;  // Attack / Movement / Defense / Support / Passive

    // 进阶
    int unlockLevel;         // 解锁等级
    float castTime;          // 施法时间

    // 等级
    int skillLevel;          // 当前等级（默认 1）
    int maxLevel;            // 最大等级（默认 5）

    // 表现
    GameObject vfxPrefab;    // 特效预制体
    AudioClip sfxClip;       // 音效
}
```

### 3.2 ActiveSkillData — 主动分支技能

```csharp
// 位置: Assets/Scripts/Skills/ActiveSkillData.cs
// 继承 SkillData
// 用于 Q/E 两槽位的主动技能

public class ActiveSkillData : SkillData
{
    ActiveBranchData lv1Data;   // Lv1 基础形态
    ActiveBranchData lv2Left;   // Lv2 左分支
    ActiveBranchData lv2Right;  // Lv2 右分支
    ActiveBranchData lv3Left;   // Lv3 左分支（从 Lv2 左升级）
    ActiveBranchData lv3Right;  // Lv3 右分支（从 Lv2 右升级）

    [NonSerialized] string chosenBranch;  // 运行时分支选择 "Left"/"Right"

    // ActiveBranchData 子结构:
    class ActiveBranchData
    {
        string branchName;   // "散射弹幕"
        float damage;        // 伤害值
        float cooldown;      // 该分支冷却
        float manaCost;      // 该分技法耗
        string description;  // 效果描述
    }
}
```

**升级流程：** Lv1 → 消耗点数 → 弹窗选分支(Left/Right) → Lv2 → 消耗点数 → Lv3（沿所选分支）

**分支选择不可逆，选 Left 后 Right 全路径级联锁定。**

### 3.3 PassiveSkillData — 被动节点

```csharp
// 位置: Assets/Scripts/Skills/PassiveSkillData.cs
// 继承 SkillData
// 每个 SO = 一条线的一个层级（5线 × 5层 = 25个）

public class PassiveSkillData : SkillData
{
    int layer;                // 1~5 (TI ~ TV)
    int lineId;               // 0~4 (5条线)
    PassiveEffect[] effects;  // 该节点的属性效果列表

    class PassiveEffect
    {
        string targetStat;    // 属性标识符 (StatId 常量)
        float value;          // 修饰值
        ModifierType type;    // Percent 或 Flat
    }
}
```

**5 条线：**

| lineId | 线名 | 效果 |
|--------|------|------|
| 0 | HP恢复 | 生命上限 +1%~+5% (Percent) |
| 1 | 伤害+攻速 | 伤害 +8%~+35%，Lv3起攻速 +10%~+20% |
| 2 | 移速+闪避 | 移速 +6%~+30%，Lv3起闪避 +15%~+30% |
| 3 | 减伤+控制 | 减伤 +5%~+25%，TV额外低血加防 |
| 4 | 法力+CD | 法力恢复/CD缩减/法力上限/法耗减免 |

**5 层解锁等级：** TI=Lv1, TII=Lv5, TIII=Lv8, TIV=Lv12, TV=Lv16

### 3.4 WeaponSkillData — 武器技能

```csharp
// 位置: Assets/Scripts/Skills/WeaponSkillData.cs
// 继承 SkillData
// 5种武器各1个 SO

public class WeaponSkillData : SkillData
{
    WeaponType weaponType;     // Sword/Bow/Staff/Hammer/DualBlades
    float damageBase;          // 基础伤害
    string effectDescription;  // UI 效果描述
}
```

**特点：** 等级固定 Lv1，不参与分支升级。装备时自动获得，卸下时移除。

### 3.5 CombinationSkillData — 组合技能（合成产出）

```csharp
// 位置: Assets/Scripts/Skills/CombinationSkillData.cs
// 继承 SkillData
// 3个产出: Lv1→双重协同, Lv2→法则领域·极, Lv3→终焉审判·灭

public class CombinationSkillData : SkillData
{
    int combinationLevel;     // 产出等级（固定 Lv2）
    string effectType;        // 如 "领域展开"
    bool destroyOnUse;        // 是否一次性（默认 false）
}
```

### 3.6 BarrierSkillData — 障碍球技能

```csharp
// 位置: Assets/Scripts/Skills/BarrierSkillData.cs
// 继承 SkillData

public class BarrierSkillData : SkillData
{
    GameObject obstacleBallPrefab;  // 障碍球预制体
    float ballSpeed;
    float maxDistance;
    float knockbackForce;
    float spawnOffset;
}
```

### 3.7 SynergyConfig — 协同联动配置

```csharp
// 位置: Assets/Scripts/Skills/SynergyConfig.cs
// 挂 SkillManager.synergyConfig 字段

public class SynergyConfig : ScriptableObject
{
    SynergyBonus[] bonuses;  // 多档 Bonus
}

class SynergyBonus
{
    int requiredLevel;       // 触发所需最低技能等级
    string bonusName;        // 显示名
    float cooldownMultiplier;
    float manaRegenBonus;
    float effectMultiplier;
}
```

## 五、SO 如何被加载到运行时

### 5.1 Inspector 拖入（编译时绑定）

| SO 类型 | 挂载位置 | 字段 | 数量 |
|---------|---------|------|------|
| ActiveSkillData | SkillManager.skillSlots[0].data | 拖入 Q.asset | 1 |
| ActiveSkillData | SkillManager.skillSlots[1].data | 拖入 E.asset | 1 |
| PassiveSkillData[] | PassiveEquipManager.allPassiveData | 拖入全部25个 | 25 |
| CombinationSkillData | CombinationCraftSystem.recipeLv1/2/3 | 拖入3个配方 | 3 |
| SynergyConfig | SkillManager.synergyConfig | 拖入配置 | 1 |

**SO 引用在编辑器中由策划/程序员手动拖入，运行时直接使用内存引用，不走 Resources.Load。**

### 5.2 查找方式

- **SkillManager** 通过 `skillSlots[i].data` 直接访问 SO 引用
- **PassiveEquipManager** 通过 `(layer, lineId) → dataIndex` 字典查询
- **WeaponSkillLink** 通过 `WeaponEquippedEvent.skillData` 接收外部系统传入的引用
- **CombinationCraftSystem** 通过 `recipeLv1/2/3` 序列化字段直接引用

### 5.3 无需 Resources.Load

当前架构中所有技能 SO 通过 Inspector 序列化引用绑定，不依赖字符串路径动态加载。这是**编译时静态绑定**的模式。

## 六、运行时数据流

### 6.1 属性修饰器管线（被动技能生效路径）

```
PassiveEquipManager.EquipPassive(layer, lineId, slot)
  │
  ├─ 查找 PassiveSkillData: dataIndex[(layer, lineId)]
  │
  ├─ 遍历 data.effects[]
  │    └─ 每个 effect → new Modifier(statId, value, type, source)
  │
  └─ statModManager.AddModifier(mod)
       │
       └─ 后续 GetFinalValue(baseValue, statId) 时参与计算:
            final = baseValue × (1 + ΣPercent) + ΣFlat
```

**同一 source 自动覆盖旧值**（来自 PassiveEquipManager 中 `{SourcePrefix}_L{layer+1}_L{lineId}` 的 source 标识）。

### 6.2 主动技能激活管线

```
PlayerController.OnUpdate()
  → SkillManager.OnPlayerUpdate()
    → CheckHotkeys()
      → 遍历 skillSlots[]，检测 Input.GetKeyDown(slot.data.hotkey)
        → TryActivate(index)
          │
          ├─ 冷却检查 (cooldownTimers[i] > 0? → return)
          ├─ 法力检查 + 消耗 (SpendMana)
          ├─ 冷却启动 (cooldownTimers[i] = cd)
          │
          └─ EventBus.Trigger(SkillActivatedEvent)
               │ (具体技能逻辑由 ISkill 实现类订阅)
```

### 6.3 存档/读档管线

```
SaveSystem.SaveGame()
  │
  ├─ CollectSkillPoints()     → SkillPointManager.CurrentSkillPoints
  ├─ CollectSkillSlots()      → 遍历 4 槽位: skillName + level + chosenBranch
  ├─ CollectPassiveSlots()    → 遍历 5 层 × 3 槽: lineId[]
  ├─ CollectWeapon()          → WeaponSkillLink 状态
  │
  └─ JsonUtility.ToJson → PlayerPrefs

SaveSystem.LoadGame()
  │
  ├─ PlayerPrefs.GetString → JsonUtility.FromJson<SaveData>
  ├─ RestoreSkillPoints()     → SkillPointManager.SetPoints()
  ├─ RestoreSkillSlots()      → FindSkillDataByName() → SkillManager.SetSlot()
  ├─ RestorePassiveSlots()    → PassiveEquipManager.EquipPassive()
  └─ RestoreWeapon()          → WeaponSkillLink.ConsumeWeaponSkill()
```

**存档以技能名称匹配 SO**（`FindSkillDataByName` 在已装载的 skillSlots 中遍历查找），不存 GUID 或路径。

## 七、创建/修改技能数据的操作流程

### 7.1 新建主动技能（如新增 R 技能）

1. 在 `CreateActiveSkillDataAssets.cs` 新增一个 `CreateSkill_R()` 方法，硬编码数值
2. 在 CreateAll() 中调用它
3. Unity 菜单 → `Tools → Create ActiveSkillData Assets` → 生成 .asset
4. 把 .asset 拖入 SkillManager.skillSlots[2].data
5. 在 SkillTreeUI 中注册新槽位的 UI 绑定（如需要）

### 7.2 修改被动数值

1. 改 `CreatePassiveSkillDataAssets.cs` 中的常量数组
2. Unity 菜单 → `Tools → Create All PassiveSkillData Assets` → 覆盖 25 个 .asset
3. Play Mode 直接生效（SO 引用不变，字段值已更新）

### 7.3 手动 Inspector 修改

也可以直接在 Unity 编辑器中选中 .asset 文件，在 Inspector 中修改字段值。适合微调。

## 九、注意事项

1. **运行时修改 SO 会持久化** — `BranchUpgradeSystem.ApplyLevelUp()` 中 `data.skillLevel = newLevel` 和 `data.chosenBranch = branch` 直接修改了 SO 实例的 `[NonSerialized]` 字段。`chosenBranch` 标了 `[NonSerialized]` 不回写磁盘，但 `skillLevel` 是基类序列化字段，会在编辑器停止播放后**保留**修改后的值。需注意。

2. **技能名匹配存读档** — `SaveSystem.FindSkillDataByName()` 用字符串匹配，改名会导致存档失效。

3. **SO 引用不跨场景** — 如果切换场景，需要重新挂载（当前项目单场景 SampleScene）。

4. **无版本管理** — 数值修改直接在 .asset 文件中，建议配合 Git 追踪 `Assets/Resources/Skills/` 目录。
