# 精灵图动画替换方案

> 当前 Player/Enemy 是简单方块，替换为精灵图动画。

---

## 分工

| 谁做 | 内容 |
|------|------|
| saika（美术+配置） | 准备精灵图、切片、创建 Animation Clip、建 Animator Controller、绑定 Prefab |
| 代码侧 | CharacterBase 翻转改 flipX、Enemy 加 Animator 引用、FSM 状态调动画 |

---

## 一、准备精灵图

**素材来源：** Aseprite / itch.io / Unity Asset Store / OpenGameArt

**规格：** 每帧等宽等高拼成一张 PNG；PPU 统一（推荐 16 或 32）；Filter Mode = Point

**需要的动画列表：**

| 角色 | 动画 | 说明 |
|------|------|------|
| Player | Idle | 站立呼吸/微动，4帧 |
| Player | Run | 跑步循环，6帧 |
| Player | Jump | 起跳→空中→落地，4帧 |
| Player | MeleeAttack | 近战挥砍，4帧 |
| Player | RangedAttack | 远程射击，4帧 |
| Player | Hurt | 受击，2帧 |
| Player | Death | 死亡，5帧 |
| Enemy | Idle | 待机 |
| Enemy | Chase | 追击 |
| Enemy | Attack | 攻击 |
| Enemy | Hurt | 受击 |
| Enemy | Death | 死亡 |

---

## 二、导入 Unity + 切片

1. PNG 拖到 `Assets/Sprites/Player/`
2. 选中图片，Inspector 设置：
   - Texture Type: **Sprite (2D and UI)**
   - Sprite Mode: **Multiple**
   - Pixels Per Unit: 和项目现有 sprite 一致
   - Filter Mode: **Point (no filter)**
   - Compression: **None**
3. 点 **Sprite Editor** → Slice → Type: **Grid By Cell Size** → 输入每帧宽高 → Slice → Apply
4. 切完后 PNG 旁边展开所有单帧

---

## 三、创建 Animation Clip

1. Window → Animation → Animation
2. 选中场景里 Player GameObject → Create → 保存到 `Assets/Animations/Player/`
3. 把单帧 sprite 拖进时间轴，调整每帧 Samples
4. Inspector 里勾 **Loop Time**（Idle/Run/Chase）

**帧时长建议：** Idle 8-10 samples，Run 6-8，Attack 4-6，Hurt 3-4

---

## 四、建 Animator Controller

**参数表（代码侧用这些名字，必须一致）：**

| 参数名 | 类型 | 用途 |
|--------|------|------|
| Speed | Float | 0=Idle, >0.1=Run |
| Grounded | Bool | true=地面, false=Jump |
| MeleeAttack | Trigger | 近战攻击 |
| RangedAttack | Trigger | 远程攻击 |
| Hurt | Trigger | 受击 |
| IsDead | Bool | 死亡 |

**连线规则：**

```
Idle → Run:          Speed > 0.1
Run → Idle:          Speed < 0.1
Any State → Jump:    Grounded = false
Jump → Idle:         Grounded = true
Any State → MeleeAttack:  MeleeAttack (trigger)
Any State → RangedAttack: RangedAttack (trigger)
Any State → Hurt:    Hurt (trigger)
Any State → Death:   IsDead = true
```

Attack/Hurt → Idle 的 Transition 勾掉 **Has Exit Time**，让攻击/受击可以立刻被新 trigger 打断。

---

## 五、绑定到 Prefab

1. 打开 Player Prefab
2. 加 **Sprite Renderer** 组件
3. 加 **Animator** 组件，Controller 拖入 `Player_Animator`
4. Sprite Renderer 的 Sprite 拖入 Idle 第一帧

Enemy 同理，Animator 参数类似（Speed/Attack/Hurt/IsDead，多了 Chase 替代 Run）。

---

## 六、代码侧改动清单

| 改动 | 文件 | 内容 |
|------|------|------|
| 翻转方式 | CharacterBase.UpdateFacing | `transform.localScale.x` → `sr.flipX`（避免翻转影响子物体和碰撞体） |
| 动画参数驱动 | PlayerController | 每帧设 `anim.SetFloat("Speed", abs(h))` + `anim.SetBool("Grounded", grounded)` |
| 攻击 trigger | PlayerCombat | Attack 时 `anim.SetTrigger(meleeAnimTrigger)`（meleeAnimTrigger 已有，值为 "MeleeAttack"） |
| 远程 trigger | PlayerCombat | RangedAttack 时加 `anim.SetTrigger("RangedAttack")` |
| Inspector 切换 | PlayerCombat | meleeVisualMode 从 Rectangle 切到 Animation |
| Enemy Animator | EnemyControllerBase | 加 `[SerializeField] Animator anim` 字段 |
| Enemy FSM 驱动 | EnemyMeleeController 等 | 各状态设 anim 参数（Speed/Move/Attack trigger） |
| Enemy 死亡 | EnemyControllerBase.Die | 播死亡动画，动画末尾 AnimationEvent 再 Destroy |
| Player 受击 | PlayerHealth | TakeDamage 时 `anim.SetTrigger("Hurt")` |
| Player 死亡 | PlayerHealth | 死亡时 `anim.SetBool("IsDead", true)` |

---

## 七、实施顺序

1. **saika 先做：** 精灵图 → 切片 → Animation Clip → Animator Controller → 绑 Prefab（不写代码也能在 Scene 里测试动画循环）
