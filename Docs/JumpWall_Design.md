# 二段跳 & 爬墙系统 · 策划案

> 版本：2.0  
> 项目：2D 横板平台动作  
> 合并二段跳与爬墙系统为统一规则文档。  
> 本文档仅含规则设计，禁止伪代码和实现细节。

---

## 1. 二段跳规则

### 1.1 核心概念

| 概念 | 含义 |
|------|------|
| 跳跃次数 | 每个"离地周期"内玩家可执行的跳跃总次数，上限为 2 |
| 离地周期 | 从双脚离地到下一次双脚触地之间的时间段 |
| 落地重置 | 双脚接触地面的那一帧，跳跃次数恢复为 2 |

### 1.2 何时能跳

- 剩余跳跃次数 ≥ 1 时，按下跳跃键（Space）执行一次跳跃。
- 剩余跳跃次数 = 0 时，按下跳跃键无效，不执行任何动作。
- 无论玩家在地面还是空中，判断逻辑完全一致：只看剩余次数。

### 1.3 跳跃次数消耗

- 每次跳跃消耗 1 次。
- 地面起跳：消耗 1 次，剩余 1 次（空中可用）。
- 空中跳跃：消耗 1 次，剩余 0 次（直到落地）。

### 1.4 落地重置规则

**落地边缘检测**：地面状态从"false"变为"true"的那一帧触发重置。

```
双脚刚接触地面 → 跳跃次数 = 2
```

- 持续站在地面上不会反复重置（因为只在边缘触发）。
- 防地面闪烁备选方案：若物理碰撞导致`grounded`在单帧内抖动，可简化为"只要当前帧在地上，跳跃次数直接设为 2"，脚蹭到地面即重置在物理上是合理行为。

### 1.5 走到悬崖边掉下去

- 玩家移动到平台边缘、未按跳跃键、自然坠落：跳跃次数保持为 2。
- 离地本身不消耗跳跃次数，只有主动按下跳跃键才消耗。
- 掉落后玩家在空中拥有完整的两次跳跃机会。

### 1.6 空中被击退

- 击退是物理力驱动，不涉及跳跃系统。
- 击退期间跳跃次数保持不变。
- 击退结束后（约 0.2 秒），若跳跃次数仍 ≥ 1，玩家可正常空中跳跃。

### 1.7 快速连续按键

- 每次按下 Space 只触发一次跳跃判断。
- 地面连续按两下：第一下地面起跳（剩余 1），第二下空中二段跳（剩余 0）。
- 地面连续按三下：前两下同上，第三下被忽略（次数已为 0）。

## 2. 爬墙状态机规则

爬墙系统使用 6 个状态。玩家必须在墙上（双射线检测确认贴墙）且不在地面，才能进入爬墙状态机。

### 2.1 状态总览

```
空状态(None)
    │
    └──→ 贴墙 + 不在地面 ──→ 缓慢下滑 (Slide)
                                  │
                  ┌───────────────┼───────────────┐
                  │               │               │
                  ▼               ▼               ▼
          按 S 键          按 W 键 > 1 秒      按跳跃键
         加速下滑          上爬 (Climb)      墙跳 (WallJump)
       (FastSlide)            │
                              │ 头顶无墙 + 目标空间无障碍
                              ▼
                          翻顶 (Vault)
```

### 2.2 各状态详细规则

#### 空状态 (None)

- 默认状态，不在墙上时不执行任何爬墙行为。
- 进入条件：任何爬墙状态退出时回到 None。

#### 缓慢下滑 (Slide)

| 项目 | 规则 |
|------|------|
| 进入条件 | 贴墙（双射线均命中）、且不在地面。不需要下落速度 < 0——即使上升途中贴墙也立即进入。 |
| 物理行为 | 垂直速度被钳制：最大下落速度 ≤ 墙滑速度。上升中进入时不做钳制（上升速度保留），转入下落时自然受限。 |
| 水平行为 | 朝墙方向的水平移动被阻止（防止角色"粘"进墙里）。远离墙方向可自由移动。 |
| 退出条件 | 不贴墙或落地 → 回到 None。按 S → 进入加速下滑。按 W 并按住超过 1 秒 → 进入上爬。按跳跃键 → 进入墙跳。 |

#### 加速下滑 (FastSlide)

| 项目 | 规则 |
|------|------|
| 进入条件 | Slide 状态下按下 S 键（下方向）。 |
| 物理行为 | 与 Slide 相同，但钳制速度增大为 Slide 的 2 倍。 |
| 退出条件 | 松开 S → 回到 Slide。不贴墙或落地 → 回到 None。按 W 并按住超过 1 秒 → 进入上爬。按跳跃键 → 进入墙跳。 |

#### 上爬 (Climb)

| 项目 | 规则 |
|------|------|
| 进入条件 | Slide 或 FastSlide 状态下，按住 W 键超过 1 秒。 |
| 物理行为 | 垂直速度固定为向上爬升速度（不加速，恒定速度上移）。水平方向朝墙的移动被阻止。 |
| 翻顶检测 | 每帧检测头顶前方是否还有墙。检测点：头顶上方 + 朝墙方向偏移。如果头顶射线未命中墙体（墙到顶了）且翻顶目标位置无碰撞体阻挡，则触发翻顶。 |
| 退出条件 | 不贴墙 → 回到 None。松开 W → 回到 Slide（非 FastSlide，即使从 FastSlide 进入）。触发翻顶 → 进入 Vault。 |
| 注 | 上爬状态下按跳跃键不响应。只有 Slide/FastSlide 才响应跳跃进入墙跳。 |

#### 翻顶 (Vault)

| 项目 | 规则 |
|------|------|
| 进入条件 | Climb 状态中检测到头顶无墙且翻顶目标位置无障碍。矮墙情况（仅脚部射线命中、头部未命中）也可直接触发翻顶。 |
| 物理行为 | 瞬间位移到平台上方（向上 + 朝墙前方）。不经过物理模拟，直接改变位置。 |
| 输入冻结 | 翻顶后冻结所有输入 0.15 秒，防止误操作。 |
| 退出条件 | 翻顶位移执行完毕后立即回到 None。 |

#### 墙跳 (WallJump)

| 项目 | 规则 |
|------|------|
| 进入条件 | Slide 或 FastSlide 状态下按下跳跃键。Climb 状态下不触发墙跳。 |
| 物理行为 | 根据当前输入方向决定跳跃方向（见下方三方向分支）。执行后立即退出到 None。 |
| 输入冻结 | 墙跳后冻结输入 0.1 秒。 |
| 注 | 墙跳是独立系统，不经过跳跃次数管理。不消耗、也不重置二段跳次数。 |

### 2.3 墙跳三方向分支

以贴**右墙**为例（贴左墙时对称反转）：

| 玩家输入 | 跳法 | 水平方向 | 力度 |
|----------|------|----------|------|
| 不按方向键 | 远离墙弹出 | 向左（远离墙） | 标准弹出力度 |
| 按远离墙方向（A/←） | 登墙跳 | 向左（远离墙） | 加大水平力度 + 加大垂直力度 |
| 按朝墙方向（D/→） | 纯正上方跳 | 水平 = 0 | 纯垂直力度 |

贴**左墙**时方向对称：
- 不按 → 向右弹出
- 按远离墙（D/→）→ 登墙跳（向右）
- 按朝墙（A/←）→ 纯上跳

## 3. 跳跃与爬墙的交互规则

### 3.1 优先级

**爬墙状态机活跃时，二段跳系统完全被绕过。** 在 Slide / FastSlide / Climb / Vault / WallJump 任一状态中，按下 Space 只触发墙跳（若在 Slide/FastSlide），不会触发二段跳。

### 3.2 墙跳与二段跳次数的关系

- 墙跳是独立物理动作，不消耗跳跃次数。
- 墙跳也不重置跳跃次数。
- 墙跳后玩家处于空中，之前剩余的跳跃次数保持不变。

**示例**：
- 地面起跳（消耗 1 次，剩余 1）→ 空中贴墙 Slide → 墙跳 → 仍在空中，剩余次数仍为 1 → 可再执行一次空中二段跳。
- 地面起跳 → 空中二段跳（剩余 0）→ 贴墙 Slide → 墙跳 → 仍在空中，剩余次数仍为 0 → 无法再跳，只能等落地。

### 3.3 落地后的统一重置

- 无论之前经历了怎样的路径（正常跳、二段跳、墙跳、翻顶后掉落），只要双脚落地，跳跃次数统一重置为 2，爬墙状态机回到 None。

### 3.4 Dash（冲刺）与跳跃

- Dash 执行期间，跳跃输入不被处理。
- Dash 结束后若仍在空中且次数足够，可正常跳跃。

### 3.5 输入冻结期间的跳跃

- 翻顶后 0.15 秒冻结期内，跳跃输入被屏蔽。
- 墙跳后 0.1 秒冻结期内，跳跃输入被屏蔽。
- 冻结期结束后恢复正常的跳跃判断。

## 4. 边界情况

| 场景 | 预期行为 | 规则依据 |
|------|---------|---------|
| 走到悬崖边自然坠落 | 跳跃次数保持 2，空中可跳 2 次 | 离地不消耗次数 |
| 地面起跳 + 空中二段跳 | 两次跳跃正常执行 | 常规消耗：2→1→0 |
| 地面起跳后立刻落地（低矮平台） | 落地帧次数重置为 2 | 边缘检测触发 |
| 空中二段跳后贴墙进入 Slide | Slide 中次数为 0，无法墙跳后再二段跳 | 墙跳不改变次数 |
| 地面起跳 → 贴墙 → 墙跳 → 空中二段跳 | 墙跳后仍有 1 次跳跃 | 墙跳不消耗次数 |
| 连续快速按跳跃键（地面 3 连按） | 只执行地面跳 + 空中跳，第三下忽略 | 次数 0 后屏蔽 |
| 空中被击退 | 跳跃次数不变，击退结束后可正常跳 | 击退是物理力，不影响跳跃系统 |
| 墙跳后落地 | 落地帧跳跃次数重置为 2 | 统一落地重置规则 |
| 翻顶后自然下落 | 落地帧跳跃次数重置为 2 | 同上 |
| 贴墙上升途中（velocity.y > 0） | 立即进入 Slide，上升速度保留，不钳制 | Slide 入口不要求下降 |
| 贴墙 Slide 中短按 W（不足 1 秒） | 不触发 Climb，保持 Slide | 上爬需要 1 秒按住 |
| 贴墙 Climb 中误按 Space | 不触发任何跳跃 | Climb 不响应跳跃输入 |
| 矮墙（仅脚部射线命中） | 触发翻顶，角色翻上平台 | 矮墙直接走翻顶逻辑 |
| 地面碰撞闪烁（单帧 grounded 抖动） | 可能触发一次额外重置，但次数本就是 2，无副作用 | 极简方案：地上就重置 |
| 同时贴两面墙（墙角内侧） | 以最后检测到的墙方向为准 | 双射线各方向独立检测 |

## 5. 可调参数一览

以下参数供策划调试，不可在此文档内修改默认值（默认值见项目 Inspector 配置）。

### 二段跳参数

| 参数 | 说明 |
|------|------|
| 最大跳跃次数 | 每次离地周期内可跳跃的总次数（当前 = 2） |
| 跳跃力度 | 每次跳跃施加的垂直力大小 |
| 空中跳力度衰减 | 空中跳是否需要力度倍率（当前 = 无衰减，统一力度） |

### 爬墙参数

| 参数 | 说明 |
|------|------|
| 墙检测距离 | 双射线检测墙体的距离 |
| 墙滑速度 | Slide 状态下的最大下落速度 |
| 加速下滑倍率 | FastSlide 相对于 Slide 的速度倍率（当前 = 2） |
| 上爬速度 | Climb 状态下的向上移动速度 |
| 上爬触发时间 | W 键需要按住多久才进入 Climb（当前 = 1 秒） |
| 翻顶检测偏移 | 翻顶时头顶检测点的高度偏移 |
| 翻顶上移距离 | 翻顶时间上移动的垂直距离 |
| 翻顶前移距离 | 翻顶时间前移动的水平距离 |
| 墙跳弹出力度 X/Y | 不按方向键时墙跳的水平和垂直力度 |
| 墙跳登墙力度 X/Y | 按远离墙方向时墙跳的水平和垂直力度 |
| 墙跳纯上力度 | 按朝墙方向时墙跳的纯垂直力度 |
| 翻顶冻结时长 | 翻顶后输入冻结的持续时间（当前 = 0.15 秒） |
| 墙跳冻结时长 | 墙跳后输入冻结的持续时间（当前 = 0.1 秒） |
