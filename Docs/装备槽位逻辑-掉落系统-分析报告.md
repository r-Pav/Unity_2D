# 装备槽位逻辑 + 掉落系统 — 分析报告

> 基于 `背包-装备系统.drawio` 反拆，聚焦数据结构、装备流转状态机、死亡掉落、enemy拾取。
> 本报告不涉及 UI 层、不写示例代码。

---

## 一、装备槽位定义（DrawIO 规格：4 槽位）

| 槽位 | 数量 | 关联系统 | 说明 |
|------|------|----------|------|
| Weapon | 1 | WeaponSkillLink — 激活/移除武器技能 | 武器装备 |
| Armor | 1 | 纯属性加成 | 护甲装备 |
| Accessory | 2 | 纯属性加成 | 饰品装备 |

与 `背包仓库装备_设计概览.md` 的 6 槽位（武器+头部+身体+腿部+饰品×2）存在差异。本报告以 DrawIO 的 4 槽位为准，未来可扩展。

---

## 二、核心数据结构

### 2.1 EquipmentSlot 枚举

```
Weapon | Armor | Accessory1 | Accessory2
```

### 2.2 ItemSO 装备子段（复用设计概览结构）

```
ItemSO.EquipmentStats:
  slot         : EquipmentSlot    // 所属槽位
  bonuses[]    : Bonus            // 属性加成数组
  weaponType?  : WeaponType       // 仅 Weapon 槽位
  weaponSkill? : WeaponSkillData  // 仅 Weapon 槽位

Bonus:
  statId   : string    // 对应 StatId 常量
  value    : float     // 加成值
  type     : ModifierType  // Percent / Flat
```

### 2.3 EquipmentManager（Player 侧运行时）

```
EquipmentManager : MonoBehaviour
  _slots[4]              // ItemInstance?[4]，索引对应 EquipmentSlot 枚举序
  _statModManager         // 缓存 StatModifierManager 引用
  _inventory              // 缓存 Inventory 引用（取放装备需要背包）
  _isDead                 // 死亡标记，锁定操作

方法:
  Equip(slot, inventoryIndex)   // 从背包装备到槽位
    ─ 前置: ItemType==Equipment, slot 匹配, 背包有空位（换装时）
    ─ 槽位非空 → 先 Unequip 旧装备到背包
    ─ 从背包移除 → 填入槽位 → AddModifiers → 通知事件
  Unequip(slot)                 // 卸下到背包
    ─ 前置: 槽位非空, 背包有空位
    ─ RemoveModifiers → 移入背包 → 清空槽位 → 通知事件
  DropAllOnDeath()              // 死亡时全部卸下生成掉落物
    ─ 遍历 4 槽位，逐个生成 DropItem，调用 RemoveModifiers
  GetEquipped(slot) → ItemInstance?
```

### 2.4 DropItem（世界掉落物）

```
DropItem : MonoBehaviour
  _itemInstance    : ItemInstance       // 携带的装备数据
  _droppedBy       : GameObject         // 来源（player/enemy）
  _level           : int                // 掉落时记录装备等级（用于 enemy 拾取数值换算）
  pickupRadius     : float              // 拾取检测半径
  ownerMask        : LayerMask          // 谁可以捡（player / enemy）
  lifetime         : float              // 超时自动销毁

方法:
  Initialize(item, level, sourceLayer)
  OnTriggerStay → 检测允许拾取方 → 生成拾取→销毁自身
```

### 2.5 Enemy Equipment（1 槽位）

```
EnemyEquipment : MonoBehaviour  // 挂 Enemy GameObject
  _slot            : ItemInstance?     // 单槽位，null=空
  _statModManager  : StatModifierManager
  _equipmentIcon   : SpriteRenderer    // 中心显示图标

方法:
  Pickup(DropItem)           // 拾取掉落物
    ─ 如果已有装备 → 旧装备掉落替换
    ─ 填入槽位 → AddModifiers（按装备等级缩放数值）
    ─ 设置 _equipmentIcon 为 50% 透明度
  DropOnDeath()              // 死亡时生成 DropItem
    ─ RemoveModifiers → 生成 DropItem → 清空槽位
  ClearIcon()                // 隐藏图标
```

### 2.6 新事件（追加到 Events.cs）

```
// 装备掉落物生成事件 — 世界生成器订阅
EquipmentDroppedEvent
  dropItem       : DropItem
  position       : Vector2

// Enemy 拾取装备事件 — AI / UI 订阅
EnemyEquipmentPickupEvent
  enemy          : EnemyControllerBase
  item           : ItemInstance
  level          : int
```

## 三、装备流转状态机

```
                            ┌─────────────┐
                            │   背包物品   │ (Inventory.slots[])
                            └──┬──────┬───┘
                     Equip()   │      │  Unequip()
                               │      │
                    ┌──────────▼──────▼──────────┐
                    │      装备槽位 (4个)         │
                    │  Weapon/Armor/Acc1/Acc2    │
                    │  + AddModifiers 生效       │
                    └────────────┬───────────────┘
                                 │ OnDeath
                    ┌────────────▼───────────────┐
                    │    DropItem (世界掉落物)    │  超时 → 销毁
                    │  level=装备等级             │
                    │  ownerMask=可拾取方         │
                    └──┬──────────────────┬──────┘
            Enemy拾取  │                  │  Player拾取
    ┌──────────────────▼──┐    ┌──────────▼──────────┐
    │ EnemyEquipment (1槽) │    │  Inventory.AddItem  │
    │ AddModifiers(缩放)   │    │  (普通捡起入背包)   │
    │ 图标50%透明          │    └─────────────────────┘
    └──────────┬───────────┘
               │ Enemy死亡
    ┌──────────▼───────────┐
    │    DropItem (再次掉落) │
    │   ownerMask 可能不同  │
    └───────────────────────┘
```

关键规则:
- 装备只能在「背包」和「槽位」间流转，不可直接从槽位丢弃（必须卸下→背包→丢弃）
- 死亡时槽位中的装备跳过背包，直接进入「掉落物」状态
- Enemy 拾取后的装备不经过背包，直接进单槽位
- Enemy 死亡时其装备再次掉落，形成「装备循环」

## 四、死亡掉落逻辑

### 4.1 Player 死亡

```
PlayerHealth.TakeDamage → HP≤0
  → EquipmentManager.DropAllOnDeath()
    for each non-null slot:
      RemoveModifiers(slot)
      Spawn DropItem(
        item      = slot.item,
        level     = item.template.level,    // 装备等级
        sourceLayer = Player
        ownerMask   = Enemy | Player        // 双方可捡
      )
      清空槽位
  → 重生时 HP 回满，装备槽位为空
```

衔接点: 修改 `PlayerHealth.TakeDamage` 中死亡分支（当前仅 `currentHealth = MaxHealth`），在重置生命值之前调用 `EquipmentManager.DropAllOnDeath()`。

### 4.2 Enemy 死亡

```
EnemyControllerBase.Die() → 已有 EnemyDeathEvent
  → [新增] EnemyEquipment.DropOnDeath()
    if _slot != null:
      RemoveModifiers(_slot)
      Spawn DropItem(
        item      = _slot.item,
        level     = _slot.item.template.level,
        sourceLayer = Enemy
        ownerMask   = Player              // 仅 Player 可捡
      )
      清空槽位 + ClearIcon()

  → [新增] 原有 EnemyDeathEvent 照常触发
  → Destroy(gameObject)
```

衔接点: 在 `EnemyControllerBase.Die()` 的 `EventBus.Trigger(EnemyDeathEvent)` 之前调用 `EnemyEquipment?.DropOnDeath()`。

### 4.3 掉落物超时

```
DropItem.lifetime 倒计时:
  → 归零时无人拾取 → 销毁 GameObject
  → 仅视觉效果（装备消失），不触发任何事件
```

## 五、Enemy 拾取装备流程

### 5.1 拾取检测

```
EnemyEquipment.OnTriggerStay(collider):
  if collider is DropItem:
    if DropItem.ownerMask 包含 Enemy:
      if _slot == null || 新装备等级 > 当前装备等级:
        Pickup(DropItem)
```

### 5.2 拾取执行

```
EnemyEquipment.Pickup(DropItem):
  1. 如果 _slot 非空:
     → RemoveModifiers(oldItem)     // 移除旧装备加成
     → Spawn DropItem(oldItem, level=oldLevel, ownerMask=Player)
        // 旧装备掉回地面，只有 Player 可捡

  2. _slot = DropItem.item
     _pickedLevel = DropItem.level

  3. AddModifiers(scaled)
     // 按等级缩放: 加成值 = 原值 × f(level)
     // f(level) = 1.0 + (level - 1) × 0.25
     // 例: level 1 → 100%, level 3 → 150%, level 5 → 200%
     // 每个 bonus 独立缩放后 AddModifier("EnemyEquip_" + instanceId)

  4. 显示图标: _equipmentIcon.sprite = item.icon
     透明度: 50% (Color.a = 0.5)

  5. 触发 EnemyEquipmentPickupEvent

  6. 销毁 DropItem
```

### 5.3 等级缩放表

| 装备等级 | 缩放倍率 | 说明 |
|----------|----------|------|
| 1 (Common) | 1.00 | 基础值 |
| 2 (Rare) | 1.25 | +25% |
| 3 (Epic) | 1.50 | +50% |
| 4 (Legendary) | 1.75 | +75% |
| 5+ | 2.00 | 上限 |

缩放公式: `scaledValue = bonus.value × min(2.0, 1.0 + (level - 1) × 0.25)`

### 5.4 图标显示规则

| 状态 | _equipmentIcon 行为 |
|------|-------------------|
| 无装备 (_slot==null) | `sprite=null`, 不渲染 |
| 有装备 | `sprite=item.icon`, `color.a=0.5` |

## 六、与现有系统的整合点

### 6.1 PlayerHealth — 死亡分支扩展

```
当前: HP≤0 → currentHealth=MaxHealth (原地满血复活，装备留在身上)
改造: HP≤0 → EquipmentManager.DropAllOnDeath() → currentHealth=MaxHealth
```

无需新增事件，在死亡分支中插入调用即可。

### 6.2 EnemyControllerBase.Die() — 死亡分支扩展

```
当前: isDead=true → OnExitCombatState → EnemyDeathEvent → Destroy
改造: isDead=true → OnExitCombatState → EnemyEquipment.DropOnDeath() → EnemyDeathEvent → Destroy
```

### 6.3 StatModifierManager — 零改动

Enemy 装备加成同样走 `AddModifier(source="EnemyEquip_xxx")`，与 Player 装备的 `"Equip_xxx"` source 前缀区分，互不干扰。同 source 覆盖规则保证换装时旧加成自动被新值替换。

### 6.4 Events.cs — 新增 2 个事件

新增 `EquipmentDroppedEvent` 和 `EnemyEquipmentPickupEvent`，供 UI / 音效 / 成就等模块订阅。

## 七、边界情况

| 场景 | 处理 |
|------|------|
| Player 死亡时装备槽为空 | DropAllOnDeath 遍历 4 槽，空槽跳过，不掉落任何东西 |
| Enemy 无装备时被击杀 | DropOnDeath 检测 _slot==null，直接返回 |
| Enemy 已有装备时拾取新装备 | 旧装备掉落回地面（ownerMask=Player），新装备入槽 |
| 掉落物超时 | 销毁自身，装备消失 |
| 掉落物同时被多个单位检测 | DropItem 内部 lock：第一个触发拾取后设置 _isPickedUp=true，后续检测返回 |
| Player 死亡重生后拾取自己的掉落 | 走普通 Inventory.AddItem 流程（从地面捡回背包，而非自动装回槽位） |
| 战斗状态限制 | 死亡时不受战斗锁定约束，DropAllOnDeath 在 HP≤0 判定后立即执行 |
| Enemy 等级缩放超出上限 | clamp 到 2.0 倍 |
| 多个 Enemy 竞争拾取 | 先到先得（Trigger 触发顺序），已拾取的 DropItem 立即销毁 |

## 八、实施优先级

| 步骤 | 内容 | 依赖 |
|------|------|------|
| 1 | EquipmentSlot 枚举 + EquipmentManager 骨架 | 无 |
| 2 | DropItem MonoBehaviour | 1 |
| 3 | Player 死亡掉落（改 PlayerHealth.TakeDamage） | 1, 2 |
| 4 | EnemyEquipment + Enemy 死亡掉落（改 EnemyControllerBase.Die） | 1, 2 |
| 5 | Enemy 拾取检测 + 等级缩放 | 2, 4 |
| 6 | 新事件 + 存档扩展 | 1, 4 |

第 1-2 步是独立模块，第 3-6 步按顺序串联。
