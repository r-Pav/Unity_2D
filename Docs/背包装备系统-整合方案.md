## 二、核心数据类与所有权

```
InventoryManager (单体/单例)
├── playerItems        : List<ItemInstance>        背包物品
├── playerEquipSlots   : EquipmentSlotData[4]      装备槽位（Weapon/Armor/Accessory0/Accessory1）
├── playerGold         : int                       金币
├── quickSlots         : ItemInstance[2]           快捷栏（引用背包物品）
├── warehouseItems     : List<ItemInstance>        仓库物品
├── warehouseMaterials : List<ItemInstance>        仓库材料区
├── activeCategory     : ItemCategory              当前分类（双面板共享）
│
└── 依赖
    ├── PlayerAttributeSystem                      主属性+派生注入
    ├── StatModifierManager                       修饰器管线
    └── EquipmentManager                          装备槽位逻辑

ItemInstance (class，非 MonoBehaviour)
├── template     : ItemSO                          ScriptableObject 模板
├── stackSize    : int                             堆叠数
├── modifiers    : ItemModifier[]                  属性加成列表（装备类物品）
├── itemEffect   : ItemEffectDataSO?               物品效果（消耗品/武器技能）

EquipmentSlotData (struct)
├── slotType     : EquipmentSlotType               Weapon/Armor/Accessory0/Accessory1
├── equippedItem : ItemInstance?                   当前装备的物品（null=空）

ItemSO (ScriptableObject)
├── itemId, itemName, itemType, itemRarity, icon, description
├── maxStack, buyPrice, sellPrice
├── equipmentStats? : EquipmentStats              仅装备类物品
└── consumableEffect?: ItemEffectDataSO             仅消耗品类物品

EquipmentStats (ItemSO 子结构)
├── slot          : EquipmentSlotType              所属槽位
├── bonuses[]     : Bonus[]                        属性加成（statId + value + type）
├── weaponType?   : WeaponType                     仅武器
└── weaponSkill?  : WeaponSkillData                仅武器

Bonus (struct)
├── statId  : string                               对应 StatId 常量
├── value   : float                                加成值
└── type    : ModifierType                         Percent / Flat
```

## 三、装备流转全状态机

```
                        ┌─────────────────┐
                        │   背包物品列表    │  InventoryManager.playerItems
                        │   (物品网格区)    │
                        └──┬──────────┬───┘
              Equip()     │          │  Unequip()
         (ItemCell拖入     │          │  (装备槽右键/点击)
          装备槽位)        │          │
              ┌───────────▼──────────▼─────────────┐
              │      装备槽位 (4个)                  │  InventoryManager.playerEquipSlots[]
              │  Weapon / Armor / Acc0 / Acc1       │
              │  → Equip时: 注入属性Modifier         │
              │  → Unequip时: 移除属性Modifier       │
              │  → 武器槽额外: 激活武器技能           │
              └────────────────┬────────────────────┘
                               │ Player死亡 → EquipmentManager.DropAllOnDeath()
              ┌────────────────▼────────────────────┐
              │     DropItem (世界掉落物)             │  超时 → 销毁
              │  item, level, ownerMask             │
              │  ownerMask = Player | Enemy          │
              └──┬────────────────────┬─────────────┘
     Enemy拾取   │                    │  Player拾取
    (ownerMask    │                    │  (ownerMask
     包含Enemy)   │                    │   包含Player)
    ┌─────────────▼───────────┐  ┌────▼───────────────┐
    │ EnemyEquipment (1槽)    │  │ InventoryManager    │
    │ 等级缩放加成值          │  │ .AddItem()          │
    │ 图标alpha=0.5           │  │ 正常入背包          │
    └─────────────┬───────────┘  └────────────────────┘
                  │ Enemy死亡 → EnemyEquipment.DropOnDeath()
    ┌─────────────▼───────────┐
    │   DropItem (再次掉落)    │  ownerMask = Player
    │   装备循环闭合           │
    └─────────────────────────┘
```

关键规则:
- 装备只能在「背包」↔「槽位」间流转，不可从槽位直接丢弃
- Player死亡 → 所有槽位装备生成 DropItem（跳过背包），ownerMask = Player|Enemy
- Enemy死亡 → 其装备生成 DropItem（跳过背包），ownerMask = Player
- Enemy已有装备再拾取 → 旧装备掉落回地面（ownerMask=Player），新装备入槽

## 四、属性计算管道（完整 8 步）

```
步骤1  主属性基础值         baseStr/baseInt/baseAgi (来自 PlayerAttrConfigSO)
         │
步骤2  装备主属性加成        EquipmentManager 汇总 4 槽位 bonusStr/bonusInt/bonusAgi
         │
步骤3  升级分配点数          assignedStr/assignedInt/assignedAgi (存档读写)
         │
步骤4  主属性终值            finalStr = baseStr + equipStr + assignedStr
         │
步骤5  派生公式计算          9 个派生值（见下表）
         │
步骤6  注入 StatModifierManager    source="AttrSys_Derived_{statId}", priority=-100
         │
步骤7  装备/技能/消耗品叠加       装备 bonus: source="Equip_{slot}_{statId}", priority=0
         │                           技能: priority=100, 消耗品: priority=200
         │
步骤8  最终值                GetFinalValue(): base × (1+Σ%) + ΣFlat，钳制后输出
```

### 派生公式表

| 派生属性 | 公式 | statId |
|---------|------|--------|
| 最大生命 | finalStr × 10 | `maxHealth` |
| 生命恢复/秒 | finalStr × 0.5 | `hpRegen` |
| 护甲 | floor(finalStr/10) × 1 | `armor` |
| 最大魔法 | finalInt × 10 | `maxMana` |
| 魔法恢复/秒 | finalInt × 0.5 | `mpRegen` |
| 技能增强 | floor(finalInt/10) × 0.05 | `skillEnhance` |
| 攻击速度 | 100 + finalAgi × 2 | `attackSpeed` |
| 闪避率 | finalAgi × 0.01 | `dodgeChance` |
| 冷却缩减 | floor(finalAgi/10) × 0.05 | `cooldownReduction` |

Bonus 加成（每10点额外）使用独立 source=`"AttrSys_Bonus_{statId}"`, priority=999，与装备%加成隔离。

## 五、属性系统接口

### 5.1 PlayerAttributeSystem — 公开 API

```
GetStrength()         → int     主属性终值（含装备+点数）
GetIntelligence()     → int
GetAgility()          → int
GetBaseStrength()     → int     裸值（仅基础+点数，不含装备）
GetDerivedValue(id)   → float   派生裸值（公式计算结果，未经修饰器管线）
AddAttributePoint(id) → void    升级加点（str/int/agi）
SetEquipmentBonus(dict) → void  装备变化时更新主属性加成
ClearEquipmentBonus() → void    装备卸下或清空
RecalculateAll()      → void    完全重算: 主属性→派生→注入→事件通知

事件:
  PrimaryAttributesChangedEvent  → 主属性变化（str/int/agi任一变动）
  DerivedAttributesChangedEvent  → 派生属性重算完成（传入 changedStatIds[]）
```

### 5.2 EquipmentManager — 公开 API

```
Equip(slot, inventoryIndex) → bool    从背包装备到槽位（满槽自动先卸旧装备）
Unequip(slot)               → bool    卸下到背包（需背包有空位）
DropAllOnDeath()            → void    死亡时4槽位全部生成DropItem
GetEquipped(slot)           → ItemInstance?  查询槽位装备
RegisterCallbacks(onEquip, onUnequip)  UI 注册刷新回调
```

### 5.3 EnemyEquipment — 公开 API

```
Pickup(DropItem)   → void    拾取掉落物（旧装备自动掉落替换）
DropOnDeath()      → void    死亡生成DropItem
ClearIcon()        → void    隐藏图标（无装备时调用）
```

### 5.4 InventoryManager — 公开 API

```
// 背包物品
AddItem(ItemSO, count)        → bool   存入背包（自动堆叠）
RemoveItem(inventoryIndex, count) → bool  从背包移除
GetFilteredItems(category)    → List<ItemInstance>  按分类+排序返回

// 装备槽位（委托 EquipmentManager）
EquipItem(inventoryIndex, slot) → bool
UnequipItem(slot)             → bool

// 仓库
DepositToWarehouse(inventoryIndex, count) → bool
WithdrawFromWarehouse(warehouseIndex, count) → bool
GetWarehouseFiltered(category) → List<ItemInstance>

// 分类同步
SetActiveCategory(category)   → void    同时更新双面板
ActiveCategory                → ItemCategory  只读

// 事件
OnInventoryChanged            → 背包内容变化（UI 订阅刷新）
OnWarehouseChanged            → 仓库内容变化
OnCategoryChanged             → 分类切换（双面板订阅）
```

## 六、拖拽交互规则

### 6.1 组件接口

| 组件 | 实现接口 | 角色 |
|------|---------|------|
| ItemCell | IBeginDragHandler + IDragHandler + IEndDragHandler + IDropHandler | 拖拽源 + 拖拽目标 |

| QuickSlotBar | IDropHandler | 仅拖拽目标（只接受消耗品） |
| EnemyEquipmentIcon | 无拖拽 | 纯显示，不接受拖入 |

### 6.2 拖拽判定表

| 源 | 目标 | 行为 | 条件 |
|----|------|------|------|
| 背包 ItemCell | 背包 ItemCell | 交换/堆叠位置 | 同面板内 |
| 背包 ItemCell | 装备槽 EquipmentSlot | 装备 | slotType匹配 + ItemType=装备 |
| 装备槽 EquipmentSlot | 背包 ItemCell | 卸下装备 | 背包有空位 |
| 装备槽 EquipmentSlot | 装备槽 EquipmentSlot | 交换装备 | 双方slotType兼容 |
| 背包 ItemCell | 仓库 ItemCell | 存入仓库 | |
| 仓库 ItemCell | 背包 ItemCell | 取出到背包 | 背包有空位 |
| 仓库 ItemCell | 仓库 ItemCell | 交换/堆叠位置 | 同面板内 |
| 背包/仓库 ItemCell | QuickSlotBar | 设置快捷栏 | ItemType=消耗品 |
| QuickSlotBar | 背包 ItemCell | 移除快捷栏（放回背包） | |

### 6.3 拖拽实现要点

- `ItemDragHandler` 在 BeginDrag 时记录源容器类型（InventoryPanel/WarehousePanel）和索引
- 透明拖拽图标跟随鼠标（RaycastTarget=false）
- EndDrag 命中有效目标 → 调用目标容器的 OnDrop 回调 → InventoryManager 执行数据操作
- EndDrag 无命中 → 物品回原位
- 右键点击快捷槽/装备槽 → 卸下/移除（不走拖拽）

## 七、分类标签同步机制

```
                 InventoryManager
                 ├── _activeCategory : ItemCategory
                 └── SetActiveCategory(cat)
                         │
             ┌───────────┼───────────┐
             ▼           │           ▼
    InventoryPanel       │     WarehousePanel
    .OnCategoryChanged   │     .OnCategoryChanged
             │           │           │
             ▼           │           ▼
    更新 CategoryTabs    │   更新 CategoryTabs
    Button 高亮状态      │   Button 高亮状态
    过滤 ItemGrid        │   过滤 WarehouseGrid
```

- InventoryManager 持有唯一的 `_activeCategory`
- 任一面板点击 CategoryTabs → 调用 `InventoryManager.SetActiveCategory()` → 触发 `OnCategoryChanged` 事件
- 两个面板都订阅 `OnCategoryChanged`，同时刷新自身的 Tab 高亮和物品列表过滤

分类枚举: `All / Consumable / Equipment / Material`（四类，按钮数量=4）

## 九、Enemy 拾取等级缩放

```
等级 → 缩放倍率   f(level) = 1.0 + (level-1) × 0.25, clamp(2.0)
  1   →  1.00x
  2   →  1.25x
  3   →  1.50x
  4   →  1.75x
  5+  →  2.00x

EnemyEquipment.Pickup(DropItem):
  加成值 = EquipmentStats.bonuses[i].value × f(DropItem.level)
  以 source="EnemyEquip_{enemyInstanceId}" 注入 StatModifierManager
```

## 十、属性系统与装备系统的衔接点

### 10.1 装备→属性

```
装备放入槽位 (EquipmentManager.Equip):
  1. 提取 EquipmentStats.bonuses[]
  2. 逐条注入 StatModifierManager:
       source = "Equip_{slot}_{statId}"
       AddModifier(statId, value, type, priority=0)
  3. 提取 bonusStr/bonusInt/bonusAgi
  4. 调用 PlayerAttributeSystem.SetEquipmentBonus(dict)
       → 内部 RecalculateAll() → 派生值重算 + 注入管线
  5. 武器槽额外: 激活 WeaponSkillLink

卸下装备 (EquipmentManager.Unequip):
  1. 以 source="Equip_{slot}_{statId}" 移除所有 modifier
  2. 调用 PlayerAttributeSystem.ClearEquipmentBonus()
       → 内部 RecalculateAll()
  3. 武器槽额外: 移除 WeaponSkillLink
```

### 10.2 护甲减伤（新增到 PlayerHealth.TakeDamage）

```
TakeDamage(rawDamage):
  1. armor = statModManager.GetFinalValue(0, "armor")
  2. afterArmor = max(1, rawDamage - armor)      // 保底1点伤害
  3. damageReduction = statModManager.GetFinalValue(1.0, "damageReduction")
  4. finalDamage = afterArmor × (1.0 - damageReduction)
  5. currentHealth -= finalDamage
```

### 10.3 攻速换算

```
PlayerCombat.GetAttackSpeedMultiplier():
  derivedAtkSpd = attrSystem.GetDerivedValue("attackSpeed")
  return derivedAtkSpd / 100.0    // 例: 130 → 1.3x 攻速
```

### 10.4 冷却缩减叠加

```
SkillManager.GetEffectiveCooldown(baseCooldown):
  cdReduction = statModManager.GetFinalValue(0, "cooldownReduction")
  cdMultiplier = statModManager.GetFinalValue(1.0, "cooldownMultiplier")
  return baseCooldown × (1.0 - cdReduction) × cdMultiplier
```

## 十一、死亡掉落衔接点

### 11.1 Player 死亡 → 修改 PlayerHealth.TakeDamage

```
当前: HP≤0 → currentHealth = MaxHealth (原地复活，装备留在身上)
改造: HP≤0 → EquipmentManager.DropAllOnDeath() → currentHealth = MaxHealth

DropAllOnDeath():
  for each non-null slot in playerEquipSlots:
    RemoveModifiers(slot)
    RemoveWeaponSkill(slot)  // 仅武器槽
    Spawn DropItem(item, level, ownerMask=Player|Enemy)
    清空槽位
  PlayerAttributeSystem.ClearEquipmentBonus()
```

### 11.2 Enemy 死亡 → 修改 EnemyControllerBase.Die()

```
当前: isDead=true → OnExitCombatState → EnemyDeathEvent → Destroy
改造: isDead=true → OnExitCombatState → EnemyEquipment.DropOnDeath() → EnemyDeathEvent → Destroy

DropOnDeath():
  if _slot != null:
    RemoveModifiers(_slot)
    Spawn DropItem(item, level, ownerMask=Player)
    清空槽位 + ClearIcon()
```

## 十三、实施顺序

按依赖链分 5 个阶段，每阶段可并行开发内部任务：

```
Phase 1: 数据层（无依赖）
  ├── 1.1 ItemSO.cs + ItemInstance.cs（SO 模板 + 运行时实例）
  ├── 1.2 枚举：EquipmentSlotType / ItemCategory / StatId 扩展
  └── 1.3 DropItem.cs Prefab

Phase 2: 属性系统（依赖 Phase 1）
```

## 十四、三份报告间的不一致与消解

| 不一致点 | 来源A | 来源B | 消解决定 | 理由 |
|---------|-------|-------|---------|------|
| 背包面板脚本名 | UI_Inventory（F:报告） | InventoryPanel（UI规范） | **InventoryPanel** | UI规范为实际Scene锚点 |
| 物品格脚本名 | UI_ItemSlot（F:报告） | ItemCell（UI规范） | **ItemCell** | 同上 |
| 装备槽脚本名 | UI_EquipSlot（F:报告） | EquipmentSlot（UI规范） | **EquipmentSlot** | 同上 |
| 仓库面板脚本名 | UI_Storage（F:报告） | WarehousePanel（UI规范） | **WarehousePanel** | 同上 |
| 运行物品类名 | Inventory_Item（F:报告） | ItemInstance（装备报告） | **ItemInstance** | 避免与MonoBehaviour命名混淆 |
| 属性管理器 | Entity_Stats（F:报告） | PlayerAttributeSystem + StatModifierManager（属性报告） | **PlayerAttributeSystem（主属性+派生）+ StatModifierManager（修饰器管线）** | StatModifierManager是现有组件，PlayerAttributeSystem新增 |
| 装备管理器 | Inventory_Player内置（F:报告） | EquipmentManager独立（装备报告） | **EquipmentManager独立** | 职责单一，Player可脱离背包系统存在 |
| 仓库材料区 | materialStash独立List（F:报告） | 未明确（UI规范有材料Tab但无独立区） | **warehouseMaterials独立List** | 保留F:报告的数据结构，UI通过分类过滤区分 |
| 4槽位 vs 6槽位 | DrawIO=4（装备报告） | 设计概览=6（F:报告） | **4槽位**（Weapon/Armor/Accessory0/Accessory1） | DrawIO为权威设计源 |
| 死亡掉落衔接 | 仅DropManager（F:报告） | EquipmentManager.DropAllOnDeath（装备报告） | **EquipmentManager.DropAllOnDeath** | 装备报告逻辑更完整，直接操作槽位避免中间状态 |
| 武器技能链接 | 未展开（F:报告提到ItemEffect） | WeaponSkillLink（装备报告） | **EquipmentManager 处理武器技能激活/移除** | 与Equip/Unequip/Drop生命周期绑定 |
| 属性加成注入时机 | Equip时遍历modifiers（F:报告） | Equip时注入StatModifierManager（属性报告） | **Equip时注入StatModifierManager + 更新PlayerAttributeSystem** | 走统一管线，避免两道加成重复计算 |
