## 二、Player GameObject 挂载

Player 上已有 PlayerController / PlayerCombat / PlayerHealth / StatModifierManager 等，新增以下脚本即可。

| 脚本 | 字段 | 类型 | 拖什么 |
|------|------|------|--------|
| EquipmentManager | `dropItemPrefab` | DropItem | 拖 Project 里的 **DropItem Prefab** |
| EquipmentManager | `statModManager` | StatModifierManager | 拖 Player 自身 StatModifierManager 组件 |
| EquipmentManager | `attrSystem` | PlayerAttributeSystem | 拖 Player 自身 PlayerAttributeSystem 组件 |
| PlayerAttributeSystem | `attrConfig` | PlayerAttrConfigSO | 拖 Project 里的 **PlayerAttrConfigSO.asset** |

## 四、DropItem Prefab 创建

1. 场景空 GameObject → 命名 `DropItem` → Layer 选 `DropItem`（先到 Project Settings → Tags and Layers 创建）
2. 加组件：**SpriteRenderer**（sortingOrder=1）+ **CircleCollider2D**（isTrigger=true, radius=0.6）+ **DropItem.cs**
3. 建子节点 `RarityFrame` → 加 SpriteRenderer（sortingOrder=2）
4. 绑定 DropItem.cs 字段：

| 字段 | 拖什么 |
|------|--------|
| `_iconRenderer` | 父级 SpriteRenderer |
| `_rarityFrame` | 子节点 RarityFrame 的 SpriteRenderer |
| `_pickupCollider` | 父级 CircleCollider2D |
| `defaultLifetime` | 30 |

5. 拖到 Project 窗口保存为 Prefab
