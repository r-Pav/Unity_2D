# 攻击手感提升方案

## 优先级排序

按性价比从高到低：

### 1. 顿帧（Hit Stop）

击中瞬间双方动画暂停 2-4 帧（0.03-0.06秒），一个 StartCoroutine 的事。

```
击中 → Time.timeScale = 0.05 → yield return WaitForSecondsRealtime(0.04) → Time.timeScale = 1
```

轻重攻击用不同时长。WaitForSecondsRealtime 不受 timeScale 影响，注意 UI 计时器要用 unscaledDeltaTime。

### 2. 屏幕震动

击中时 Camera 微小位移 ±2-5 像素。Cinemachine Impulse 或手写 CameraShake：
- 轻攻击：振幅 2px, 持续 0.1s, 频率高
- 重攻击：振幅 5px, 持续 0.2s, 频率低
- 暴击：振幅加倍

### 3. 击退 + 受击反馈

- 被击方小幅后推（tween 位移，非传送）
- SpriteRenderer 闪白 2-3 帧
- 播放受击动画/切换受击 sprite
- 血条立即扣减，带滞后条更好（橙色条减速追上白色条）

### 4. 攻击轨迹/残影

- 近战：武器上绑 TrailRenderer，挥砍时拉出弧线
- 通用：攻击帧生成 2-3 个半透明 player sprite 残影

### 5. 音效

- 挥空声 ≠ 击中声
- 击中用低频"肉感"音效（闷响，非清脆金属）
- 不同武器类型不同音效
- 音效延迟 > 30ms 手感报废

### 6. 数字跳出

DamagePopup prefab + DOTween：
- 暴击大号数字、变色、弹跳曲线
- 普通伤害小字直线浮起

## 实施建议

前三个（顿帧 + 震屏 + 受击反馈）半天工作量，手感翻倍。
